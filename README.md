Python Alarm Clock

About the Project:

This is a simple Alarm Clock application developed using Python. It checks the current time and alerts the user when the specified alarm time is reached.

Features:

- Set an alarm using the 24-hour time format
- Check the current time
- Play a beep sound when the alarm rings

Technologies Used:

- Python 3
- datetime module
- time module
- winsound module (Windows)

How to Run:

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python alarm_clock.py

5. Enter the alarm time in "HH:MM:SS" format.

Example: "20:30:00"

Learning Outcomes:

- Python loops
- Conditional statements
- Working with date and time
- Using Python modules
